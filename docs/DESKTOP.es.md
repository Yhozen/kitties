# El escritorio de un kitty

Abre [kitties.rccpr.tech](https://kitties.rccpr.tech) e inicia sesión. Cada kitty puede usar una
máquina virtual de Boat. Desde la web puedes ver su escritorio, tomar el control y copiar texto.
Los controles permiten iniciar, dormir, restaurar y actualizar el escritorio. La primera
instalación puede tardar varios minutos; los reintentos reutilizan los pasos ya instalados.

Las aprobaciones y las solicitudes de ayuda continúan automáticamente al responder. Tras una
recuperación de datos, actualiza las credenciales del escritorio y vuelve a autorizar las
conexiones. Consulta la [guía completa](DESKTOP.md) y la [recuperación](effect/RECOVERY.md).
