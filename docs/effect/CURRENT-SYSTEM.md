# Current system: contracts and defects

Audited on 2026-11-01 at commit `7f408a17a33e87c29701dc0ec0ca89df3b75947a`.
These links remain useful after the Go code is removed. Contracts describe behavior worth carrying
forward; defects are evidence for the rewrite, not compatibility requirements.

| Area | Contracts to carry forward | Defects or deliberate changes | Source |
|---|---|---|---|
| HTTP and identity | Single authenticated owner; cookie mutations require same origin. Health and session have explicit semantics. Unknown API routes must not fall through to HTML. | Replace local bearer/query tokens and local-token discovery with verified Cloudflare Access identity. Separate hooks and guest ingress from owner routes. | [internal/gateway/serve.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/gateway/serve.go) |
| State and recovery | A successful persistent mutation has reached authoritative durable storage. Stale writers are fenced. Restore verifies identities before routing to a replacement. | Go mirrors files through a global mutex and terminates on exhausted storage failures. Use per-entity SQLite, typed failures and independent R2 blobs. | [internal/statefs/statefs.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/statefs/statefs.go) |
| Desktop actions | Never automatically replay an effect whose outcome is unknown; cancellation is not evidence that the effect did not happen. | Interrupted Go work requires explicit continuation. New guest intent receipts reconcile after reconnect; only genuinely unknown outcomes need owner review. | [internal/orchestrator/activity.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/orchestrator/activity.go) |
| Human control | Receipts bind exact kitty, remote identity and generation; revoke on epoch change or input failure; release drains in-flight work and refuses queued input. Agents cannot act during a human grant. | Fresh SSH/API preparation on input adds seconds. Move dispatch to a persistent fenced guest channel. | [internal/orchestrator/control_receipt_test.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/orchestrator/control_receipt_test.go) |
| Approvals | Rules auto/ask/never; demand levels 1/2/3/4/5 require 2/4/6/12/never consecutive approvals. Approved work must resume durably. | [internal/approvals/approvals.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/approvals/approvals.go) |
| Cron | Five numeric fields: minute/hour/day/month/weekday; lists, ranges, positive steps, Sunday 0 or 7. Restricted day-of-month and weekday use OR. | Webhooks | Verify GitHub HMAC and Stripe timestamped signatures (five-minute tolerance) over raw bytes before accepting. Owner routes remain authenticated. | Drop query-string secrets, cap raw bytes, deduplicate deliveries, and queue instead of dropping when busy. Access currently prevents public webhook delivery. | [internal/gateway/agenda.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/gateway/agenda.go) |
| Provider requests | Omit temperature unless explicitly configured, including explicit 0. Preserve reasoning between native tool rounds. Use non-strict tool schemas unless strict-safe. Codex Responses uses stream=true and store=false. | Token deltas, bounded screenshot context and prompt caching replace whole-response and full-image-history requests. | [internal/provider/families.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/provider/families.go) |
| Provider URL policy | Validate URL schemes/hosts before network access; reject credentials in URLs, local/private/link-local addresses and unsafe redirects. | Apply the same policy to MCP/OAuth/native HTTP and DNS results, not only provider settings. | [internal/provider/provider.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/provider/provider.go) |
| Boat identity | An API read must report owner access. Bind deployment, logical computer, remote ID and generation. Names detect conflicts but never grant access. An inventory failure cannot authorize replacement. | Lifecycle generation scans stay out of the warm input path. Next receives a separate deployment ID and kn- namespace. | [internal/boat/generation.go](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/boat/generation.go) |
| Boat create and restore | Persist the exact request bytes and idempotency key before dispatch. Retry the identical request within 24 hours. Labels dropped by restore require an exact persisted create receipt. Beyond 24h an unknown create fails closed. | No adoption of existing Go VMs/checkpoints and no migration. | [internal/boat/README.md](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/boat/README.md) |

Deleting a saved checkpoint remains a distinct irreversible operation. | [internal/boat/README.md](https://github.com/Yhozen/kitties/blob/7f408a17a33e87c29701dc0ec0ca89df3b75947a/internal/boat/README.md) |
